 2026: a digital odyssey — 프로젝터 상영용 플레이리스트
 김건우 제19회 개인전 · 갤러리한빛
════════════════════════════════════════════════════════

전시장 프로젝터 전용 순환 상영 플레이어입니다.
작품 사본 15개가 projector/works/ 안에 들어 있으며,
같은 내용이 서버에도 올라가 있습니다.

─── 실행 방법 (권장 · 인터넷 주소로 열기) ───────────────

1. 맥북에어를 프로젝터에 연결합니다 (HDMI/USB-C).
2. Chrome 으로 아래 주소를 엽니다.

     https://kimgunwoo.kr/19th/projector/index.html

   (전시 사이트 첫 화면 우상단의 프로젝터 아이콘을 눌러도
    같은 화면으로 들어갑니다.)
3. 화면을 클릭하면 전체화면으로 순환 상영이 시작됩니다.
   01번부터 15번까지 차례로 상영 후 다시 01번으로 돌아갑니다.
   작품 사이에는 제목·수식 타이틀 카드가 잠시 표시됩니다.

※ 왜 파일(file://)이 아니라 인터넷 주소인가요?
   어차피 작품이 Three.js 라이브러리를 CDN에서 받아오므로
   인터넷은 어느 쪽이든 반드시 필요합니다. 그런데 파일로 열면
   Chrome이 마이크 권한을 기억하지 못해 08·15번 차례마다
   권한 창이 화면에 뜰 수 있습니다. 인터넷 주소로 열면
   처음 한 번만 허용하면 이후로는 묻지 않습니다.

※ 비상용 (인터넷은 되는데 서버가 안 열릴 때):
   맥북의 이 폴더에서 index.html 을 직접 Chrome으로 열어도
   똑같이 동작합니다. 단 위의 마이크 권한 창이 뜰 수 있습니다.

※ 인터넷 연결 필요: 연결이 끊기면 화면이 자동으로 재시도하며,
   인터넷이 돌아오면 스스로 복구됩니다.

─── 키보드 조작 ─────────────────────────────────────────

  Space   일시정지 / 재개 (현재 작품에 머무름)
  → / ←   다음 / 이전 작품으로 즉시 이동
  F       전체화면 켜기/끄기
  H       상태 표시 (현재 작품 · 남은 시간)
  I       마우스로 작품 조작 허용 (기본은 꺼짐 — 무인 상영용)
  Esc     전체화면 해제 (브라우저 기본)

※ I 를 켜고 작품 화면을 클릭하면 키보드 입력이 작품 쪽으로
   넘어가 Space·←·→ 가 듣지 않습니다. 화면 맨 아래 여백 등
   작품 바깥을 한 번 클릭하면 다시 듣습니다.
   무인 상영 중에는 I 를 켜지 마세요.

─── 상영 시간 바꾸기 ────────────────────────────────────

기본: 작품당 120초 (14번 Black Hole Voyage만 190초 —
붕괴 주기 180초를 온전히 보여주기 위해).

· 전체 일괄 변경: 주소 뒤에 ?dur=초 를 붙여 엽니다.
    예) …/projector/index.html?dur=180  → 모든 작품 3분씩
· 특정 작품부터 시작: …/projector/index.html?start=7  → 7번부터
· 특정 작품만 변경: 맥북 폴더의 index.html 을 텍스트 편집기로
  열어 상단 "설정" 부분에서 해당 작품의  dur:null  을
  dur:150  처럼 초 단위 숫자로 바꾼 뒤 서버에 다시 올립니다.

─── 전시 전 맥북 설정 (권장) ────────────────────────────

1. 전원 어댑터를 연결해 두세요.
2. 시스템 설정 → 잠금 화면 →
   "디스플레이가 꺼져 있을 때 화면 보호기 시작" 안 함,
   "배터리 사용 시/전원 어댑터 연결 시 디스플레이 끄기" 안 함.
   (플레이어 자체도 화면 꺼짐 방지를 요청하지만 이중 안전용)
3. 알림 방해 금지(집중 모드) 켜기 — 상영 중 알림 배너 방지.
4. 프로젝터 연결 후 시스템 설정 → 디스플레이에서
   "미러링" 대신 프로젝터를 주 화면으로 쓰거나,
   미러링 시 해상도를 프로젝터 최대 해상도로 맞추세요.
5. 사운드 작품이 자동으로 소리를 내므로 맥북(또는 프로젝터/
   스피커) 음량을 전시장에 맞게 미리 조절해 두세요.
6. 첫 시작 후 08번·15번 작품 차례가 되면 Chrome이 마이크
   권한을 물어봅니다 — "허용"을 눌러 주세요. 인터넷 주소로
   열었다면 이 창은 처음 한 번만 뜨고 이후에는 묻지 않습니다.
   소리가 필요 없으면 그냥 맥북 음량을 0으로 하면 됩니다.
7. 전시 시작 전에 한 번 리허설로 08·15번까지 돌려 마이크
   권한을 미리 허용해 두면, 관람 시간에는 창이 뜨지 않습니다.

─── 화질 관련 ───────────────────────────────────────────

이 폴더의 작품 사본은 본 사이트와 달리 프로젝터용으로
항상 최고 화질(입자 수 최대 · 안티앨리어싱 · 고해상도 렌더링)
로 고정되어 있습니다. 15번 작품의 30초 수면 모드도 꺼져 있어
계속 활성 상태로 상영됩니다.

─── 사운드 자동 활성화 ──────────────────────────────────

사운드 기능이 있는 세 작품은 상영이 시작되면 모든 기능이
자동으로 켜집니다 (버튼 조작 불필요):

  08 Lambert Nebula      마이크 입력 자동 ON — 전시장의
                         소리에 반응해 성운이 일렁입니다.
  14 Black Hole Voyage   드론 사운드 자동 ON — 180초 붕괴
                         주기에 맞춰 소리가 전개됩니다.
  15 Kerr Plasma         신시사이저 사운드 + 마이크 입력
                         모두 자동 ON.

작품이 바뀔 때 이전 작품의 사운드는 타이틀 카드가 화면을
덮는 순간 함께 종료되므로 두 작품의 소리가 겹치지 않습니다.

─── 문제 해결 ───────────────────────────────────────────

· 검은 화면이 계속될 때 → 인터넷 연결 확인 (자동 재시도 중).
· 상영이 멈춘 것처럼 보일 때 → Space(일시정지 여부 확인),
  H를 눌러 상태 표시 확인.
· 완전히 초기화하려면 → 브라우저 새로고침 (Cmd+R) 후
  다시 클릭으로 시작.
