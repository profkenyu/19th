 2026: a digital odyssey — 심연의 방정식
 작품별 관람법 및 조작 방법
════════════════════════════════════════════════════════════════════

■ 공통 인터페이스 (모든 작품)

  · BACK 버튼(우하단)      : 이전 화면으로 돌아갑니다.
  · NEXT 버튼(우하단)      : 다음 작품으로 이동합니다.
                             (15번에서는 NEXT 대신 FIN이 나타납니다)
  · 보이저 라인(하단 중앙) : 15개의 눈금 = 15개의 작품. 눈금을 누르면
                             해당 작품으로 바로 이동, 맨 왼쪽 지구본
                             아이콘은 목록(관측소)으로 가는 길입니다.
                             모바일 세로 화면에서는 왼쪽에 세로로 표시.
  · UNIVERSE #XXXXXX       : 접속할 때마다 새로 생성되는 당신만의
                             우주 좌표. 같은 우주는 두 번 존재하지
                             않습니다.
  · 진입 연출              : 작품 사이를 이동할 때 짧은 영문 문장이
                             떠올랐다 사라집니다(시네마틱 모드 전용).
                             서두르지 말고 문장을 읽고 들어가세요.
  · 관람 태도              : 모든 장면은 느리게 호흡하도록 설계되어
                             있습니다. 화면이 변해가는 과정을 기다리며
                             지켜보는 것이 가장 좋은 관람법입니다.

■ 사운드 안내
  08번(마이크), 14번(앰비언트 사운드), 15번(사운드+마이크)은 소리를
  사용합니다. 조용한 곳이라면 소리를 켜고 감상해 보세요. 사운드는
  버튼을 눌러야만 켜지며, 마이크 사용 시 브라우저가 권한을 물어봅니다.


────────────────────────────────────────
 01 · RGB GALAXY ENGINE
────────────────────────────────────────
 조작 : 마우스를 움직이면(모바일: 터치 드래그) 시선이 은하 주위를
        부드럽게 따라 움직입니다. 별도의 클릭 조작은 없습니다.
 관람 : 세 나선팔의 색이 RGB 색상환을 따라 서서히 순환하는 것을
        지켜보세요. 화면 가장자리로 시선을 옮기면 은하의 옆모습과
        두께가 드러납니다.

────────────────────────────────────────
 02 · HYPERBOLIC NEBULA
────────────────────────────────────────
 조작 : 마우스 이동 = 패럴랙스 카메라. 커서를 움직이면 성운이 시차를
        두고 기울어집니다.
 관람 : 입자 성운(안쪽)과 노이즈 가스 구름(바깥쪽)이 서로 다른 속도로
        회전합니다. 두 겹의 흐름이 어긋나는 지점을 찾아보세요.

────────────────────────────────────────
 03 · RIEMANN DREAMS
────────────────────────────────────────
 조작 : 마우스 이동 = 시점 이동. 화면 클릭 = 클릭 지점에서 소수의
        파문(블룸)이 피어납니다. 모바일에서는 기기를 기울이면
        (자이로) 바다가 함께 기웁니다.
 관람 : 파문을 여러 곳에 연달아 만들어 파도가 겹치는 간섭을 만들어
        보세요. 소수 바다의 물결은 클릭이 없어도 스스로 출렁입니다.

────────────────────────────────────────
 04 · QUANTUM SINGULARITY
────────────────────────────────────────
 조작 : 포인터 이동 = 시선 표류(Gaze Drift). 클릭 조작은 없습니다.
 관람 : 좌상단 계기판의 Evolution Phase와 Current Prime Factor를
        함께 보세요. 작품은 30분 주기로 ERA OF GENESIS →
        RIEMANN CHRONICLES → HYPERBOLIC CATHEDRAL → QUANTUM
        SINGULARITY → THERMODYNAMIC DEATH 다섯 단계를 진화합니다.
        오래 머무를수록 다른 우주를 만나는 작품입니다.

────────────────────────────────────────
 05 · DUAL GALAXY
────────────────────────────────────────
 조작 : 마우스 이동/터치 = 시점에 미세한 표류를 더합니다. 카메라는
        기본적으로 스스로 두 은하 사이를 항해합니다.
 관람 : 두 은하의 색이 만나는 경계면을 주목하세요. 안개의 색도
        시간에 따라 함께 순환합니다.

────────────────────────────────────────
 06 · LAMBERT NEBULA: ESSENTIAL
────────────────────────────────────────
 조작 : 마우스 이동 = 시점 표류. 카메라는 스스로 성운을 공전합니다.
 관람 : 시리즈(06→07→08)의 첫 편. 단일한 나선(W₀)의 형태를 눈에
        담아 두세요 — 다음 두 작품에서 이 형태가 어떻게 겹쳐지고
        소리에 반응하게 되는지 비교하는 재미가 있습니다.

────────────────────────────────────────
 07 · LAMBERT NEBULA: ARCHIVE
────────────────────────────────────────
 조작 : 마우스 이동 = 시점 표류. 화면 클릭 = 중심 코어가 크게
        맥동합니다(Core Pulse).
 관람 : 두 개의 가지(W₀ ∪ W₋₁)가 겹쳐 만든 이중 나선 구조를
        찾아보세요. 코어의 맥동은 클릭 없이도 심장박동처럼
        은은하게 반복됩니다.

────────────────────────────────────────
 08 · LAMBERT NEBULA  (오디오 리액티브)
────────────────────────────────────────
 조작 : · AUDIO INPUT 버튼 = 마이크 켜기/끄기 (브라우저 권한 허용
          필요). 켜면 주변 소리가 성운을 움직입니다.
        · 분리 모드 버튼(ALL / W₀ / W₋₁) = 두 가지 중 하나만
          떼어내 관찰할 수 있습니다.
        · 화면 클릭 = 코어 펄스. 마우스 이동 = 시점 표류.
 관람 : 마이크를 켜고 목소리를 내 보세요 — 저음은 성운의 큰 몸을,
        고음은 입자의 잔떨림을 흔듭니다. 우측 데이터 모니터에서
        BASS/HIGH 수치가 실시간으로 반응하는 것을 확인할 수
        있습니다. 조용히 서 있으면 성운도 고요해집니다.

────────────────────────────────────────
 09 · BESSEL BLOOM
────────────────────────────────────────
 조작 : 화면 누르기/터치 = 그 지점에 파원(波源) 생성. 파원은 시간이
        지나면 스스로 잦아듭니다(Sources Fade).
 관람 : 서로 다른 위치에 파원을 2~3개 만들어 파동이 교차하는 간섭
        무늬를 만들어 보세요. 손을 멈추면 수면이 천천히 고요로
        돌아가는 과정까지가 작품입니다.

────────────────────────────────────────
 10 · LORENZ BUTTERFLY
────────────────────────────────────────
 조작 : 화면 클릭/터치 = 계(系)에 섭동을 가합니다. 매개변수 ρ가
        28→36으로 튀었다가 서서히 28로 되돌아옵니다.
 관람 : 클릭 직후 나비의 날개가 흐트러졌다가, 시간이 지나며 다시
        본래의 끌개(attractor)로 수렴하는 복원 과정을 지켜보세요.
        '카오스 속의 질서'를 몸으로 확인하는 조작입니다.

────────────────────────────────────────
 11 · ODYSSEY: ESSENTIAL
────────────────────────────────────────
 조작 : 포인터 이동 = 시선 표류. 카메라는 자율 궤도(Autonomous
        Orbit)로 블랙홀을 공전합니다.
 관람 : 지평선 가장자리에서 빛나는 광자 고리(Photon Ring)와, 안쪽
        일수록 빨라지는 별들의 회전 속도 차이를 주목하세요.

────────────────────────────────────────
 12 · ODYSSEY: ARCHIVE
────────────────────────────────────────
 조작 : 포인터 이동 = 시선 표류. 카메라 자율 궤도.
 관람 : 11번과 짝을 이루는 작품. 광자 고리 바깥에 푸르게 떠 있는
        아인슈타인 링, 그리고 중심에 가까울수록 뒤틀리는 좌표계
        끌림(Kerr Drift)을 11번과 비교하며 보세요.

────────────────────────────────────────
 13 · EVENT HORIZON
────────────────────────────────────────
 조작 : 드래그(누른 채 이동) = 시선 표류. 카메라의 접근/이탈은
        자동으로 반복됩니다.
 관람 : 하단 계기판이 이 작품의 핵심입니다.
        · R/Rs   = 지평선까지의 거리 (1에 가까울수록 위험)
        · dτ/dt  = 나의 시간이 흐르는 속도 (지평선에 가까울수록 느려짐)
        · PHASE  = APPROACH(접근) → HORIZON SKIM(지평선 스침) →
                   DEPARTURE(이탈)
        HORIZON SKIM 순간, 시간 지연 수치가 곤두박질치는 것을
        확인해 보세요.

────────────────────────────────────────
 14 · BLACK HOLE VOYAGE
────────────────────────────────────────
 조작 : · 사운드 버튼 = 절차적 앰비언트 사운드 켜기/끄기 (권장!)
        · 드래그 = 시선 표류.
        · 나머지는 전자동 — 180초의 항해가 무한 반복됩니다.
 관람 : 한 사이클(3분)을 처음부터 끝까지 보는 것을 권합니다.
        성운 표류 → 아인슈타인 링 → 지평선 진입 → 슬릿-스캔 시간
        파편화(108–138초) → 대붕괴(145–180초) → 재생성. 화면의
        DESCENT(하강률)와 한글 문구가 현재 악장을 알려줍니다.
        사운드를 켜면 하강에 따라 소리도 함께 무너집니다.

────────────────────────────────────────
 15 · KERR PLASMA CATHEDRAL  (피날레)
────────────────────────────────────────
 조작 : · 드래그 = 시공간 회전. 좌우로 끌면 블랙홀의 스핀이
          손끝을 따라 걸립니다.
        · 사운드 버튼 = 절차적 사운드 켜기/끄기.
        · 마이크 버튼 = 주변 소리가 플라스마의 저음/고음 반응으로
          흘러듭니다 (권한 허용 필요).
        · FIN 버튼 = 마지막 의식(儀式). 플라스마가 서서히 침묵으로
          승천한 뒤, 전시의 마지막 질문(코다)으로 이어집니다.
 관람 : 아무것도 하지 않으면 우주가 천천히 잠듭니다 — "관측이
        멈추면, 우주는 잠든다". 화면을 건드려 다시 깨워 보세요.
        관측과 존재의 관계를 손으로 경험한 뒤, 준비가 되었을 때
        FIN을 누르세요. 되돌릴 수 없는 버튼은 아니니 안심하셔도
        됩니다 — 코다에서 언제든 처음으로 돌아올 수 있습니다.
