# 핸드오프 스펙: 메인 페이지 (index.html · Cinematic 모드)

**대상:** 김건우 교수 제19회 개인전 《2026: a digital odyssey — 심연의 방정식》 웹사이트 메인 페이지
**작성일:** 2026-07-24 · WCAG 2.1 AA 접근성 수정 반영본 기준

---

## 개요

전시의 관문 역할을 하는 단일 화면(풀 뷰포트, 스크롤 없음) 페이지. 두 개의 장면으로 구성된다.

1. **오프닝** — 블랙홀 WebGL 셰이더 위에 전시 타이틀과 EMBARK 버튼. 세션당 1회만 표시.
2. **관측소(Observatory)** — 성운 WebGL 배경 위에 작품 15점 목록 + 라이브 프리뷰 패널. 작품 선택 시 해당 작품 HTML로 전체 화면 전환.

일반 웹 방문과 **무인 전시 키오스크 운영**(`?kiosk=1`) 두 가지 맥락을 모두 지원한다.

## 키오스크 모드 (무인 전시)

- 진입 `index.html?kiosk=1`, 해제 `?kiosk=0` (세션에 유지)
- **45초** 무입력 → 어트랙트: 작품을 **9초** 간격 자동 순회 + 하단 힌트 표시
- **210초** 무입력 → 세션 초기화 후 오프닝으로 리셋
- 모든 입력(pointer/key/wheel/touch)에서 즉시 중단·타이머 리셋

## 성능

- **저사양 판정(lowPowerMode):** Android / 뷰포트 ≤768px / 가로 낮은 화면 / 코어 ≤4 / 메모리 ≤4GB 중 하나면 활성
- 저사양 시: DPR 상한 0.72(배경)·1.25(오프닝), 24fps 캡, 셰이더 옥타브·별 레이어 축소, 이중 성운 레이어 제거 / 고사양: DPR 1.5~1.6, 45~60fps
- WebGL 실패 시 2D 캔버스 폴백(별 필드 / 정적 블랙홀)
- 오프닝 종료 1.7초 후 오프닝 GL 컨텍스트 명시 해제(`WEBGL_lose_context`) — 이중 렌더링 방지
- 배경 렌더는 `entered` 이전·탭 비가시 상태에서 정지. bfcache 복귀(`pageshow persisted`) 시 재개
- resize는 rAF당 1회로 병합, 프리뷰 iframe은 화면에 보일 때만 로드

## 엣지 케이스

- **WebGL 미지원:** 2D 폴백 자동 적용, 기능 손실 없음
- **뒤로가기(bfcache):** 전환 레이어 해제, 목록 재구성, 오프닝 스킵 상태 복원
- **프리뷰 미표시 상태(세로 모바일)에서 선택:** iframe 로드하지 않음(리소스 절약)
- **탭 전환/최소화:** 렌더 루프 정지, 복귀 시 재개 — rAF 기반 진입 연출은 페이지가 비가시 상태면 일시정지됨(의도된 동작)
- **긴 작품명/수식:** 수식은 ellipsis(max-width 38%), 제목은 nowrap — 새 작품 추가 시 15자 내외 권장

## 접근성 (구현 완료 사항 — 회귀 금지)

- **초점 순서:** 오프닝 중에는 EMBARK만 탭 가능(`#obs`·`#fixed-top-left`·`#guide-link`에 `inert`, 진입 시 해제)
- **코다:** dialog 시맨틱 + 초점 이동/트랩/복귀, Esc 닫기, 닫힘 상태 `visibility:hidden`
- **라이브 영역:** 프리뷰 메타 `aria-live="polite"`
- **키보드:** Tab/↑↓/Enter/Space/Esc 전체 조작 가능, `:focus-visible` 스타일 존재
- **랜드마크:** `#obs`=main, 모드 토글=navigation. h1은 장면당 1개만 노출
- **대비:** 위 토큰 표의 알파값 하한 유지
- **보류(알려진 이슈):** 작품 행 리스트 시맨틱·방문 상태 SR 전달(#5), 200% 확대 잘림(#6), reduced-motion 시 배경 셰이더 감속(#12)
